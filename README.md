- **Đề tài:** Website Quản lý Blog cá nhân

## Hướng dẫn chạy dự án

1. Cài đặt các thư viện:
```bash
npm install
```

2. Chạy ứng dụng:
```bash
npm run dev
```

Mở trình duyệt truy cập: `http://localhost:3000`
